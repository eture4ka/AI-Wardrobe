# Образ AI — локальна версія

Мобільний застосунок-гардероб з AI-стилістом. Один файл `index.html`: HTML, CSS і JavaScript разом.

## Запуск у VS Code

1. Відкрийте цю папку у VS Code (File → Open Folder).
2. Встановіть розширення **Live Server** (автор Ritwick Dey).
3. Правою кнопкою на `index.html` → **Open with Live Server**. Сторінка відкриється в браузері.
4. Натисніть 🔑 угорі та вставте свій API-ключ Claude.

Без ключа застосунок теж працює: речі можна додавати вручну, але розпізнавання фото й підбір образів будуть вимкнені.

## Де взяти API-ключ

1. Зареєструйтесь на https://console.anthropic.com
2. Поповніть баланс (запити платні, але дешеві: розпізнавання однієї речі коштує частки цента).
3. Розділ **API Keys** → Create Key → скопіюйте ключ `sk-ant-...`.

## Важливо про безпеку

Ключ зберігається тільки у вашому браузері (localStorage) і не записаний у коді, тому код можна викладати на GitHub. Але цей спосіб підходить лише для навчального прототипу: у справжньому продукті запити до AI мають іти через власний сервер (бекенд), щоб ключ ніхто не побачив.

## Що де в коді

- `CATS`, `STYLES`, `SEASONS` — категорії, стилі та сезони одягу.
- `DEMO` — приклад гардеробу з 12 речей.
- `Store` — збереження даних у localStorage браузера.
- `AI.json()` — запит до Claude API; моделі задані в `MODEL_FAST` і `MODEL_SMART`.
- `$("#photoIn").onchange` — обробка фото та розпізнавання речі.
- `generate()` — підбір образів: тут промпт, який можна змінювати.
