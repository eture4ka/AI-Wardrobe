# SmartWardrobe — гардероб з AI-стилістом

Оцифруй гардероб → зрозумій свій стиль → створюй образи → вирішуй, чи варто купувати → оживляй забуті речі → проходь fashion-челенджі.

Навчальний прототип з предмета «Основи підприємництва та бізнес-планування в ІТ». Увесь застосунок — один файл `index.html`.

## Що вміє

| Функція | Як працює |
|---|---|
| **Оцифровка гардеробу** | Фотографуєте річ — AI визначає назву, категорію, колір, стиль, сезон і теплоту |
| **Образ + погода + місце** | Вписуєте місто, застосунок сам підтягує поточну температуру й погоду, далі AI збирає 3 образи під подію |
| **Мій стиль** | AI аналізує гардероб і формує профіль: стиль, улюблені кольори, що носите найчастіше. Далі це враховується в підборі |
| **Купувати чи ні?** | Фото речі в магазині → скільки у вас схожих, скільки нових комбінацій додасть, ціна за комбінацію, вердикт і приклади образів |
| **Забуті речі** | Показує, що давно не було в образах, і генерує для цих речей нові комбінації |
| **Розумна валіза** | Місто + кількість днів → прогноз погоди → образи на кожен день з мінімуму речей |
| **Примірка на мені** | Експеримент: генерує фото образу на вашому фото. Потребує моделі з генерацією зображень |
| **Челенджі й рівні** | 4 челенджі, бали та рівні Style Beginner → Fashion Explorer → Smart Stylist → Style Master |
| **Вартість носіння** | Вказали ціну — застосунок рахує, скільки коштує одне носіння кожної речі |

## Запуск у VS Code

1. Відкрийте цю папку у VS Code (File → Open Folder).
2. Встановіть розширення **Live Server** (автор Ritwick Dey).
3. Правою кнопкою на `index.html` → **Open with Live Server**.
4. Натисніть 🔑 угорі та вставте API-ключ Gemini.

Без ключа працює все, крім AI: можна додавати речі вручну й завантажити демо-гардероб.

## Безкоштовний API-ключ

1. Зайдіть на https://aistudio.google.com і увійдіть через Google-акаунт.
2. **Get API key** → **Create API key**.
3. Скопіюйте ключ (`AIza...`) і вставте в застосунок через 🔑.

Картка не потрібна. Безкоштовний тариф має денний ліміт запитів — для демонстрації вистачає. Погода береться з Open-Meteo, яка теж не потребує ключа.

## Демонстрація на захисті

1. **Завантажити приклад** — з'явиться гардероб з 13 речей і реальною історією носіння: видно вартість носіння кожної речі та 6 речей, які давно без діла.
2. **Профіль → Проаналізувати мій стиль** — AI описує стиль користувача.
3. **Підібрати** — вписати своє місто, натиснути «Погода», обрати подію, згенерувати образи.
4. **Купувати?** — сфотографувати будь-яку річ і показати вердикт з цифрами.
5. **Профіль → забуті речі** — натиснути на річ, застосунок складе образи саме з нею.
6. **Челенджі** — почати один і показати прогрес.

Перед захистом прогоніть сценарій один раз, щоб не витрачати денний ліміт наживо.

## Безпека

Ключ зберігається лише в браузері користувача (localStorage) і не записаний у коді, тому репозиторій можна публікувати. Для навчального прототипу цього достатньо, але у справжньому продукті запити до AI мають іти через власний сервер — інакше ключ видно в браузері. Це хороший пункт для слайда з ризиками та дорожньої карти.

## Структура коду

Усе в `index.html`, розділено коментарями:

| Блок | Що робить |
|---|---|
| `CATS`, `STYLES`, `SEASONS`, `EVENTS`, `CHALLENGES`, `LEVELS` | довідники та налаштування гри |
| `DEMO` | демо-гардероб з історією носіння |
| `Store` | збереження в localStorage |
| `AI` | запити до Gemini; моделі в `MODEL_FAST`, `MODEL_SMART`, `MODEL_IMAGE` |
| `currentWeather`, `forecast` | погода з Open-Meteo, без ключа |
| `newCombos`, `costPerWear`, `forgottenItems` | аналітика гардеробу |
| `challengeProgress` | підрахунок прогресу челенджів з історії носіння |
| `generate()` | підбір образів — тут головний промпт |
| `$("#buyIn").onchange` | «Купувати чи ні?» |
| `$("#packGo").onclick` | «Розумна валіза» |
| `tryOn()` | примірка на фото |
